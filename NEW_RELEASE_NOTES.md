### BetterAngle Pro v5.5.295
- **Fix: HUD Task View Visibility**. Fixed an issue where the HUD was still visible as a separate window in Windows Task View (Win+Tab).
- **Fix: HUD Accidental Dragging**. Enforced holding the `Ctrl` key to drag the HUD overlay, preventing accidental movement when clicking on the desktop.
- **Fix: System Tray & Hotkey Toggle Logic**. The Dashboard no longer minimizes when using the global hotkey or clicking the tray icon while the app is visible but behind other windows. It now correctly brings the dashboard to the front. The app now also responds to single-clicks on the system tray icon instead of requiring a double-click.
